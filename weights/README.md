# Weights

Do not commit model weights to this repository.

This directory records which weights are needed, where they should live on the
machine, and which large files are intentionally missing from GitHub.

## Required For Real Inference

Mock mode does not need any model weights:

```bash
python inference_pipeline/mac_server.py --mock_control --mock_action stop
```

Real TrackVLA/PFEM inference needs the following assets.

| Asset | Source | Local path example | Why it is needed |
| --- | --- | --- | --- |
| OpenTrackVLA source repo | `https://github.com/om-ai-lab/OpenTrackVLA` | `/Users/mythrise/科研实习/OpenTrackVLA` | `inference_pipeline/mac_server.py` imports `model.py` and `harness/` from this repo. |
| OpenTrackVLA 0.6B HF checkpoint | `omlab/opentrackvla-qwen06b` | `OpenTrackVLA/ckpts_hf/opentrackvla-qwen06b` | Official 0.6B planner/baseline checkpoint. Key file: `model.safetensors`. |
| Qwen backbone | `Qwen/Qwen3-0.6B` | Hugging Face cache or `OpenTrackVLA/ckpts_hf/qwen3-0.6b` | Native `OpenTrackVLA(ModelConfig())` loads this LLM backbone through Transformers. |
| DINOv3 vision tower | `facebook/dinov3-vits16-pretrain-lvd1689m` | `OpenTrackVLA/ckpts_hf/dinov3-vits16-pretrain-lvd1689m` | Official visual tokenization in `cache_gridpool.py`. This is gated on Hugging Face. |
| SigLIP vision tower | `google/siglip-so400m-patch14-384` | `OpenTrackVLA/ckpts_hf/siglip-so400m-patch14-384` | The second vision tower used with DINOv3. |
| PFEM checkpoint | trained locally by `scripts/train_pfem.py` | `OpenTrackVLA/ckpts_pfem/pfem_epoch3.pt` | Harness weights used by the car-control server. |

## Optional / Experiment Assets

| Asset | Path pattern | Notes |
| --- | --- | --- |
| Legacy OpenTrackVLA checkpoints | `OpenTrackVLA/ckpts/model_epoch*.pt` | Used with `CKPT=/path/to/model_epoch*.pt` in some OpenTrackVLA eval flows. |
| Cached visual tokens | `OpenTrackVLA/cache*/` or project-specific cache root | Speeds up training, but can be regenerated. |
| Habitat / EVT-Bench assets | `OpenTrackVLA/data/`, `OpenTrackVLA/sim_data/` | Needed for simulator evaluation, not for basic car TCP tests. |
| Collected car data | `track_car/data/collected/` | Generated by `data_pipeline/collect_data.py`; not suitable for GitHub. |

## Download Commands

Run these in the OpenTrackVLA repo, not inside `track_car`:

```bash
cd /Users/mythrise/科研实习/OpenTrackVLA

hf download omlab/opentrackvla-qwen06b \
  --local-dir ckpts_hf/opentrackvla-qwen06b

hf download Qwen/Qwen3-0.6B \
  --local-dir ckpts_hf/qwen3-0.6b

hf download google/siglip-so400m-patch14-384 \
  --local-dir ckpts_hf/siglip-so400m-patch14-384
```

DINOv3 is gated. Request access on Hugging Face first, then download:

```bash
hf download facebook/dinov3-vits16-pretrain-lvd1689m \
  --local-dir ckpts_hf/dinov3-vits16-pretrain-lvd1689m

export DINOV3_MODEL_PATH=/Users/mythrise/科研实习/OpenTrackVLA/ckpts_hf/dinov3-vits16-pretrain-lvd1689m
```

PFEM checkpoints are produced by training:

```bash
cd /Users/mythrise/科研实习/OpenTrackVLA
python scripts/train_pfem.py \
  --train_json data/car_train_labeled.jsonl \
  --epochs 4 \
  --batch_size 2 \
  --lr 3e-4 \
  --out_dir ckpts_pfem
```

Expected output:

```text
ckpts_pfem/pfem_epoch0.pt
ckpts_pfem/pfem_epoch1.pt
ckpts_pfem/pfem_epoch2.pt
ckpts_pfem/pfem_epoch3.pt
```

## Local Manifest

Use `weights_manifest.example.json` as the template for local configuration:

```bash
cp weights/weights_manifest.example.json weights/weights_manifest.local.json
# edit weights/weights_manifest.local.json
python weights/resolve_weights.py --manifest weights/weights_manifest.local.json
```

To inspect the example manifest without failing on placeholder paths:

```bash
python weights/resolve_weights.py --manifest weights/weights_manifest.example.json --allow_missing
```

## Not Uploaded

The following file types/directories are intentionally excluded:

```text
OpenTrackVLA/
ckpts_hf/
ckpts/
ckpts_pfem/
*.pt
*.pth
*.safetensors
data/
sim_data/
world_rollouts/
*.jpg
*.jpeg
*.png
*.mp4
*.mov
*.avi
weights/*.local.json
```

Raspberry Pi vendor files such as `z_uart.py` are also not included. Put them
on the Pi next to the runtime code, or install them in the Pi Python path.
